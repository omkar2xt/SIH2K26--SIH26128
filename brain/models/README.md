# PASHU-RAKSHA Brain — Model Registry Foundation

## Purpose
Manages ML/AI model metadata, versions, evaluation metrics, and deployment statuses.

## Deployment Statuses
- `EXPERIMENTAL` — Research prototype model.
- `VALIDATED` — Field-validated against clinical/lab ground truth datasets.
- `PRODUCTION` — Active deployment model.
- `DEPRECATED` — Retired model.

## Principle
No unvalidated ML model is promoted to `PRODUCTION` without accredited veterinary field validation.
